## 🧩 Current project — School Management System
A lightweight school management tool that includes:
- Student and staff records (CRUD)
- Attendance tracking and basic reporting
- Local desktop GUI (Tkinter) for offline usage
- Flask backend to serve API and optional web UI
- SQLite by default with optional PostgreSQL support

Quick local run (example):
```bash
# copy env and install deps
cp .env.example .env
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt

# run the backend (Flask)
export FLASK_APP=app
flask run

# or run the desktop UI
python gui/main.py
```
